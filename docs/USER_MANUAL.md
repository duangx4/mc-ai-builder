## 快速开始

### 第一步：配置 API
1. 点击右上角的 **⚙️ 设置** 按钮
2. 填写以下信息：
   - **API Key**: 你的 OpenAI API 密钥
   - **Base URL**: API 地址（默认：https://api.openai.com/v1）
   - **Model**: 模型名称（推荐：gpt-4 或 gpt-4o-mini）
3. 点击 **保存设置**

### 第二步：选择生成模式
界面左侧有三种模式可选：
- **⚡ 快速生成** - 适合快速创建和修改建筑
- **📐 蓝图模式** - 适合大型建筑的规划和审批
- **🎯 精确修改** - 适合修改建筑群中的特定部分

### 第三步：开始建造
根据选择的模式，按照提示操作即可。

## 三种生成模式

### ⚡ 快速生成模式

**适用场景**：
- 快速创建简单建筑（房屋、塔楼、小型城堡）
- 修改现有建筑
- 尝试不同设计方案（并发生成）

**使用方法**：
1. 在输入框中描述你的需求，例如：
   ```
   建造一个中世纪风格的石制塔楼，10x10，高度20格
   ```
2. 点击 **发送** 或按 Enter
3. AI 会生成建筑代码并自动执行
4. 建筑会立即出现在 3D 视图中

**并发生成**（多方案对比）：
1. 在设置中将 **并发数** 设为 2-4
2. AI 会同时生成多个不同的设计方案
3. 使用变体切换按钮查看不同方案
4. 选择最满意的方案

**修改现有建筑**：
1. 确保场景中已有建筑
2. 输入修改需求，例如：
   ```
   把屋顶改成红色陶瓦
   ```
3. AI 会识别现有建筑并进行修改

### 📐 蓝图模式（工作流模式）

**适用场景**：
- 大型建筑项目（宫殿、城堡、庄园）
- 需要详细规划和审批的建筑
- 团队协作项目

**使用流程**：

#### 1. 需求收集（5个问题）
点击 **发送** 后，系统会询问：
- **建筑类型**：房屋、城堡、塔楼、庙宇等
- **规模**：小型、中型、大型、巨型
- **风格**：中世纪、现代、东方、幻想等
- **材料偏好**：石材、木材、砖块、混合
- **特殊功能**：地下室、阳台、花园等

#### 2. 蓝图生成
系统会生成详细的建筑蓝图，包括：
- **建筑信息**：类型、风格、尺寸
- **SVG 平面图**：彩色俯视图，显示房间布局
- **施工计划**：7个阶段（地基→主体→楼层→屋顶→外装→内装→景观）
- **材料清单**：所需方块数量统计
- **预估信息**：方块总数、建造时间

#### 3. 审批操作
查看蓝图后，你可以：
- **✅ 批准并开始建造** - 执行建造
- **✏️ 修改需求** - 重新规划
- **❌ 取消** - 放弃此次建造

#### 4. 建造执行
批准后，系统会：
1. 生成建造代码
2. 执行代码，放置方块
3. 显示建造结果

**蓝图模式的优势**：
- ✅ 清晰的可视化（SVG 平面图）
- ✅ 详细的施工计划
- ✅ 材料清单提前预览
- ✅ 审批机制避免错误

### 🎯 精确修改模式

**适用场景**：
- 修改建筑群中的某一个建筑
- 局部改造（不影响其他部分）
- 需要保持整体风格一致性的修改

**使用流程**：

#### 1. 框选区域
1. 切换到 **精确修改** 模式
2. 点击 **📦 开始框选** 按钮
3. 在 3D 视图中：
   - **第一次点击**：设置起点
   - **第二次点击**：设置终点
   - 绿色半透明框表示选中区域
4. 确认框选范围正确

#### 2. 输入修改需求
在输入框中描述你的修改，例如：
```
把这个建筑改成塔楼，增加2层，保持中世纪风格
```

#### 3. 分析和规划（三阶段工作流）
系统会自动进行：
- **阶段1：分析** - 识别建筑类型、风格、周边环境
- **阶段2：规划** - 生成修改计划和施工步骤
- **阶段3：代码生成** - 生成修改代码

#### 4. 审批修改计划
系统会展示：
- **修改概述**：一句话总结
- **区域分析**：建筑类型、风格、连接类型
- **修改约束**：需要注意的限制
- **设计建议**：AI 的建议
- **施工步骤**：详细的施工阶段
- **风格保持**：如何保持风格一致
- **边界处理**：如何处理与周边的连接

你可以：
- **✅ 批准并开始修改** - 执行修改
- **❌ 取消修改** - 放弃此次修改

#### 5. 执行修改
批准后：
1. 执行修改代码
2. **只修改选中区域**
3. **区域外的方块完全保留**
4. 显示修改结果

**精确修改的核心优势**：
- ✅ 只修改选中部分，其他建筑不受影响
- ✅ 智能感知周边风格，保持一致性
- ✅ 详细的分析和规划，减少错误
- ✅ 适合复杂建筑群的局部改造

**典型使用场景**：
- 宫殿群中修改某一个宫殿
- 城堡群中改造某一个塔楼
- 村庄中翻新某一栋房屋

## 功能详解

### 3D 视图控制
- **旋转**：鼠标左键拖拽
- **缩放**：鼠标滚轮
- **平移**：鼠标右键拖拽
- **聚焦**：双击方块

### 对话历史
- **查看历史**：所有生成记录保存在对话框中
- **清空历史**：点击对话框顶部的清空按钮
- **复制代码**：点击消息中的代码块可复制

### 并发生成
1. 打开 **⚙️ 设置**
2. 将 **并发数** 设为 2-4
3. 发送需求后，会同时生成多个方案
4. 使用 **变体 1/2/3** 按钮切换查看
5. 选择最满意的方案

### Agent 模式
Agent 模式会进行更深入的推理：
1. 打开 **⚙️ 设置**
2. 勾选 **Agent 模式**
3. AI 会进行多步推理（分析→规划→生成）
4. 适合复杂建筑

### 导出功能
- **导出为 JSON**：保存建筑数据
- **导出为代码**：保存 VoxelBuilder 代码
- **分享**：生成分享链接

## 常见问题

### Q1: 生成的建筑不符合预期怎么办？
**A**: 
1. 尝试更详细的描述（尺寸、风格、材料）
2. 使用蓝图模式，通过问答明确需求
3. 使用并发生成，对比多个方案

### Q2: 如何修改已生成的建筑？
**A**: 有两种方式：
1. **快速修改**：直接描述修改需求（适合简单修改）
2. **精确修改**：框选区域后修改（适合局部改造）

### Q3: 精确修改时，其他建筑会被影响吗？
**A**: 不会。精确修改只会修改选中的区域，区域外的所有方块都会被完整保留。

### Q4: 蓝图模式和快速生成有什么区别？
**A**: 
| 特性 | 快速生成 | 蓝图模式 |
|------|---------|---------|
| 速度 | 快 | 较慢 |
| 详细程度 | 简单 | 详细 |
| 可视化 | 无 | SVG 平面图 |
| 审批 | 无 | 有 |
| 适用场景 | 简单建筑 | 大型项目 |

### Q5: 为什么生成失败？
**A**: 可能的原因：
1. **API Key 无效** - 检查设置中的 API Key
2. **网络问题** - 检查网络连接
3. **配额超限** - OpenAI API 配额用完
4. **模型不支持** - 尝试更换模型

### Q6: 如何提高生成质量？
**A**:
1. 提供详细的描述（尺寸、风格、材料、功能）
2. 使用蓝图模式，通过问答明确需求
3. 使用 GPT-4 等更强大的模型
4. 启用 Agent 模式进行深度推理

### Q7: 如何选择合适的模式？
**A**:
- **快速试验** → 快速生成
- **大型项目** → 蓝图模式
- **局部修改** → 精确修改

## 技巧和最佳实践

### 描述建筑的技巧
好的描述应该包含：
1. **尺寸**：长×宽×高（例如：15x15x20）
2. **风格**：中世纪、现代、东方、幻想等
3. **材料**：石材、木材、砖块等
4. **功能**：房间布局、特殊功能

**示例**：
```
建造一个中世纪风格的城堡主塔
- 尺寸：20x20，高度30格
- 材料：石砖、橡木
- 功能：4层楼，每层一个房间，顶层有塔楼
- 细节：底层有拱门入口，窗户使用玻璃板
```

### 使用蓝图模式的技巧
1. **明确需求**：5个问题认真回答
2. **查看平面图**：确认布局合理
3. **检查材料清单**：确认材料可接受
4. **阅读施工计划**：了解建造过程

### 精确修改的技巧
1. **框选准确**：确保选中目标建筑
2. **描述清晰**：说明要修改成什么样
3. **保持风格**：AI 会自动识别周边风格
4. **分步修改**：复杂改造可以分多次进行

### 并发生成的技巧
1. **设置 3-4 个并发**：平衡速度和选择
2. **对比方案**：仔细查看每个变体
3. **混合优点**：可以基于某个方案再修改

### 性能优化建议
1. **避免超大建筑**：单个建筑不超过 100x100x100
2. **分批建造**：大型项目分多次建造
3. **定期清理**：清空不需要的建筑和对话历史

### 常见错误和解决
| 错误 | 原因 | 解决方法 |
|------|------|---------|
| "API Key 无效" | 密钥错误 | 检查设置中的 API Key |
| "请先框选区域" | 未框选 | 点击"开始框选"并在视图中选择区域 |
| "操作正在进行中" | 重复提交 | 等待当前操作完成 |
| "生成的代码为空" | AI 返回异常 | 重试或简化需求描述 |
