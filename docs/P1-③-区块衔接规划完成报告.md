## 任务完成情况

### ✅ 已完成任务

#### 1. 衔接表构建 (buildAdjacencyTable)
- **文件**: `src/utils/adjacencyEngine.js`
- **功能**:
  - 遍历任务对，检测面相邻（共享 2D 面、轴对齐）
  - 对角接触（仅棱/点）不算相邻
  - 返回衔接边列表：`{ a, b, axis, faceA, faceB, overlapRange, gap, heightALine, heightBLine, aligned }`
- **测试**: 8 个测试用例，覆盖 x/y/z 轴相邻、间隙检测、对角不相邻、高度对齐检测

#### 2. 衔接校验与自动修复 (validateSeams)
- **文件**: `src/utils/adjacencyEngine.js`
- **功能**:
  - **贴边连续性**: gap=0 无问题，gap>0 生成填充代码，gap<0（重叠）标记为 fatal
  - **墙顶对齐**: 高度差 ≤1 无问题，1<差≤3 自动拉齐，差>3 标记为 fatal
  - **水平基准面**: 检查各区块 groundY 与全局基准面是否一致
  - **自动修复**: 
    - gap 1-3 格 → 生成缝合代码（用公共材质填充）
    - 高度差 2-3 格 → 生成补高代码（拉齐到较高值）
- **测试**: 10 个测试用例，覆盖完美衔接、缝隙填充、重叠检测、高度拉齐、groundY 校验

#### 3. runPartitionedBuild 集成
- **文件**: `src/utils/partitionEngine.js`
- **集成点**: 在 mergeBlockCodes 前调用 validateSeams
- **流程**:
  1. 构建衔接表
  2. 校验衔接问题
  3. fixable 问题 → 自动生成填充代码追加到合并代码后
  4. fatal 问题 → 记录警告（未来可扩展为重生成）
  5. 衔接信息通过 onPlan 回调返回给 UI
- **返回值增强**: 添加 `seams: { edges, issues, filled }` 字段

#### 4. 默认版本切换
- **文件**: `src/App.jsx`, `src/utils/versionConfig.js`
- **更改**:
  - App.jsx L267: `useState('1.21')` → `useState('1.20.1')`
  - versionConfig.js: 新增 1.20.1 版本条目，标记 `isLatest: true`
