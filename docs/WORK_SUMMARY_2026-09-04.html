🎯 五种用户模式

⚡ 快速模式

适用于小型简单建筑（< 500 方块）。单次 AI 调用，10秒生成，适合快速原型。

⏱️ 10秒 💰 $0.01 ⭐⭐⭐

🎨 智能模式

适用于中型建筑（500-1500 方块）。三阶段流程（规划→建造→质检），平衡质量和速度。

⏱️ 30秒 💰 $0.03 ⭐⭐⭐⭐

📐 蓝图模式

适用于大型建筑（1500-2500 方块）。交互式规划，生成施工计划，用户审批后建造。

⏱️ 2-5分钟 💰 $0.05 ⭐⭐⭐⭐⭐

🚀 极致模式

适用于超大建筑（> 2500 方块）。蓝图规划 + 视觉反馈 + 多 Agent 并行，追求极致质量。

⏱️ 3-5分钟 💰 $0.10 ⭐⭐⭐⭐⭐

🎯 精确修改模式

适用于局部调整。用户框选区域，AI 仅重建该部分，自动匹配周围风格。

⏱️ 20秒 💰 $0.02 ⭐⭐⭐⭐

💡 关键创新点

1. 智能推荐系统

基于提示词分析和方块数量估算，自动推荐最适合的模式。

  • 建筑类型识别（帐篷、房子、城堡、宫殿...）
  • 修饰词分析（大型、精致、简单...）
  • 方块数量估算（200-5000+ 方块）
  • 智能路由到对应模式

2. 精确修改模式

你提出的创新功能，解决了局部调整的痛点。

  • 3D 区域选择工具（拖动框选）
  • 上下文感知（分析周围方块，自动匹配风格）
  • 边界平滑连接（无缝融入现有建筑）
  • Before/After 对比预览

3. 极致模式的四阶段流程

整合了蓝图模式的规划优势和视觉反馈的迭代能力。

  • Phase 0: 蓝图规划（交互问答，用户审批）
  • Phase 1: 快速草图（基于蓝图，低保真）
  • Phase 2: 视觉分析（Vision AI 发现问题）
  • Phase 3: 多 Agent 建造（并行，精细）

🌟 你的关键贡献

创新想法

在今天的讨论中，你提出了多个关键创新：

1. Blueprint 模式（类似 grillme）

你提出在大型工程前用交互式问答拷问用户需求，生成图文并茂的施工计划，避免浪费。 这个想法成为了蓝图模式的核心设计。

2. 视觉反馈系统

你提出让 AI 先生成体素 3D 模型，然后多模态模型识别图像和提示词，再生成次轮提示词， 最后接入多 agent 模式建造。这个想法演化为极致模式的视觉反馈迭代机制。

3. 精确修改模式

你提出让用户框选区域，AI 仅在该区域内重建，不改变其他建筑，用于精确修改。 这个想法成为了第五种模式，解决了局部调整的痛点。

4. 方块数量标准调整

你指出我对方块数量的判断有问题，最小的房子也要 200-500 个方块，建议使用 500/1500/2500 的分割标准。 这个修正让模式推荐更加准确。

5. 体素生成的洞察

你指出"体素模型生成能力是强的，弱的是把体素模型转化成 MC 对应方块的能力"。 这个准确的技术判断帮助我们明确了技术方向。

6. 极致模式整合蓝图

你提出把蓝图模式的预规划部分加入到极致模式，形成更完整的四阶段流程。
