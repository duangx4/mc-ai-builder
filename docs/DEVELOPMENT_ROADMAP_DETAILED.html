P1.1 - 模式选择器 UI 组件

用户界面的核心入口，所有模式的起点

✅ 具体任务

  • 设计模式选择器界面（5个模式卡片）

    • 智能模式卡片（🎨 图标，推荐标签）
    • 蓝图模式卡片（📐 图标，大型建筑）
    • 极致模式卡片（🚀 图标，超大建筑）
    • 精确修改卡片（🎯 图标，局部调整）
  • 实现模式切换逻辑
  • 添加智能推荐按钮
  • 显示预估时间和成本
  • 响应式设计（移动端适配）
