P1.4 - 智能模式五步工作流（融合版）

用户视角 3 阶段 | 技术实现 5 步骤

⏱️ 4天 难度: 中高 影响: 极高 ✨ 融合优化版

📝 设计理念

融合两个版本的优势：

  • ✅ 用户视角简洁 - 3 个清晰的大阶段（规划设计 → 精细建造 → 质量优化）
  • ✅ 技术实现细粒度 - 5 个内部步骤保证质量和可靠性
  • ✅ 智能质量检查 - AI 驱动的三维度评估（结构/风格/细节）
  • ✅ 快速失败机制 - 语法预检节省成本，避免浪费

🔄 完整工作流程

📋 阶段 1: 规划设计（用户看到）

步骤 1.1: PLANNING

  • 调用 read_skill 读取风格知识
  • 分析用户需求和建筑类型
  • 生成结构化 BuildingPlan JSON
  • 输出：蓝图（style, blocks, materials）
🏗️ 阶段 2: 精细建造（用户看到）

步骤 2.1: CONSTRUCTION

  • 基于蓝图调用 generate_code
  • 分层建造（地基 → 墙体 → 屋顶）
  • 输出：VoxelBuilder 代码

步骤 2.2: SYNTAX_CHECK（新增优化）

  • 本地快速验证代码语法
  • 检查是否生成方块（> 0）
  • ✅ 通过 → 进入质量检查
  • ❌ 失败 → 立即修复，跳过质量检查（节省成本）
✨ 阶段 3: 质量优化（用户看到）

步骤 3.1: QUALITY_CHECK（新增核心）

  • AI Agent 三维度评估：
  • ① 结构完整性检查（缺失/比例/对称）
  • ② 风格一致性验证（材料/造型/主题）
  • ③ 细节丰富度评估（装饰/变化/层次）
  • 生成 QualityReport JSON（问题清单 + 修复建议）
  • 评分阈值：>= 7.0 通过，< 7.0 需优化

步骤 3.2: REFINEMENT（条件执行）

  • 双模式修复：
  • 模式 A: 语法错误修复（来自 SYNTAX_CHECK）
  • 模式 B: 质量问题改进（来自 QUALITY_CHECK）
  • 使用 modify_code 应用修复建议
  • 重新执行 QUALITY_CHECK（最多 2 次循环）

💡 核心创新点

  • 快速失败机制 - SYNTAX_CHECK 在昂贵的 Quality Check 前拦截语法错误
  • AI 智能质量检查 - 不仅验证代码执行，更评估建筑美学质量
  • 三维度评估体系 - 结构/风格/细节全面打分（0-10 分）
  • 双模式修复 - 区分语法错误和质量问题，精准修复
  • 用户体验优化 - 5 个内部步骤映射为 3 个用户阶段，清晰直观

✅ 具体实现任务

  • 修改 src/utils/smartEngine.js
    • 新增 PHASES.SYNTAX_CHECK 阶段
    • 新增 PHASES.QUALITY_CHECK 阶段（替代简单 Validation）
    • 实现 executeQualityCheck() 函数（AI 质量评估）
    • 增强 executeRefinementPhase() 支持双模式修复
  • 创建质量检查系统
    • 设计 QualityReport JSON Schema
    • 实现三维度评估 Prompt
    • parseQualityReport() 解析器
    • 质量阈值配置（7.0 通过，8.5 优秀）
  • 用户体验映射
    • getUserProgress() - 5步骤映射3阶段
    • 阶段进度条显示（30% / 70% / 100%）
    • 友好的阶段名称（规划设计/精细建造/质量优化）
  • 性能优化
    • SYNTAX_CHECK 快速失败节省 API 成本
    • 小建筑（< 50 方块）跳过质量检查
    • 最多 2 次质量优化循环，避免无限重试

smartEngine.js Agent V2 工具 技能系统 结构化 JSON AI 质量评估
