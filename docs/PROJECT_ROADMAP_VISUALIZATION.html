🎯 四种用户模式

⚡ 快速模式 (Fast Mode)

适用于小型简单建筑（< 500 方块）。单次 AI 调用，快速生成，适合原型验证。

⏱️ 10秒 💰 $0.01 📦 < 500 方块 ⭐ 质量：⭐⭐⭐

🎨 智能模式 (Smart Mode)

适用于中型建筑（500-1500 方块）。三阶段流程（规划→建造→质检），平衡质量和速度。

⏱️ 30秒 💰 $0.03 📦 500-1500 方块 ⭐ 质量：⭐⭐⭐⭐

📐 蓝图模式 (Blueprint Mode)

适用于大型复杂建筑（1500-2500 方块）。交互式规划，生成施工计划，用户审批后建造。

⏱️ 2-5分钟 💰 $0.05 📦 1500-2500 方块 ⭐ 质量：⭐⭐⭐⭐⭐

🚀 极致模式 (Ultra Mode)

适用于超大型建筑（> 2500 方块）。视觉反馈 + 多 Agent 协作，追求极致质量。

⏱️ 3-5分钟 💰 $0.10 📦 > 2500 方块 ⭐ 质量：⭐⭐⭐⭐⭐

🗓️ 详细实施时间线

1

第一周：基础整合 (5天)

  • Day 1-2: 创建模式选择器 UI 组件 (ModeSelector.jsx)
  • Day 2: 实现智能推荐算法 (modeRecommender.js)
  • Day 3: 整合快速模式（已有 Agent V2）
  • Day 4: 设计三阶段 Workflow 架构
  • Day 5: 创建 Workflow 基础框架
2

第二周：智能模式实现 (5天)

  • Day 6: 实现 Planning Agent（查知识库、规划蓝图）
  • Day 7: 实现 Building Phase（按蓝图建造）
  • Day 8: 实现 Quality Check Agent（检查修复）
  • Day 9: 三阶段 Workflow 串联和测试
  • Day 10: UI 进度展示和错误处理
3

第三周：蓝图模式实现 (5天)

  • Day 11-12: 设计和实现问答流程（5个关键问题）
  • Day 13: 实现蓝图生成器（平面图、材料清单）
  • Day 14: 蓝图可视化展示（ASCII + 数据）
  • Day 15: 审批流程和 Workflow 集成
4

第四周：优化和测试 (3天)

  • Day 16: 智能推荐算法优化（基于用户反馈）
  • Day 17: 性能优化和错误处理完善
  • Day 18: 全面测试和文档完善

⚠️ 风险与挑战

技术风险

  • Workflow 暂停和恢复机制（蓝图审批需要）
  • 多 Agent 协调逻辑复杂度
  • Vision API 成本控制

用户体验风险

  • 模式选择可能让用户困惑（需要清晰引导）
  • 等待时间过长（需要进度反馈）
  • 成本透明度（需要提前告知）

缓解策略

  • 提供"智能推荐"默认选项
  • 实时进度展示和预计时间
  • 每个模式显示预计成本
  • 允许中途取消
