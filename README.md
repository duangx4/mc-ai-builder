# MC AI Builder v2 🎮✨

> 基于 AI 的 Minecraft 建筑生成器 - 从文字描述到完整建筑

## 🌟 核心特性

### 🎨 五种生成模式

1. **快速模式** ⚡
   - 单轮生成，10-30 秒完成
   - 适合小型建筑（< 500 方块）
   - 低成本，快速预览

2. **智能模式** 🧠（推荐）
   - 三阶段生成：规划 → 建造 → 优化
   - 适合中型建筑（500-1500 方块）
   - 质量与速度平衡

3. **蓝图模式** 📐
   - 交互式问答收集需求
   - 可视化蓝图预览
   - 用户审批后建造
   - 适合大型建筑（1500-2500 方块）

4. **极致模式** 🚀
   - AI 视觉反馈迭代改进
   - 最多 3 轮优化
   - 目标质量 8.5/10
   - 适合超大型建筑（> 2500 方块）
   - Vision API 成本：~$0.045-0.20

5. **精确修改模式** 🎯
   - 局部区域框选修改
   - 上下文感知，风格匹配
   - 保持周边建筑一致性
   - 适合已有建筑的修改

### 🛠️ 核心功能

#### 3D 实时预览
- **WebGL 渲染**：基于 Three.js 的高性能 3D 引擎
- **体素系统**：优化的方块渲染，支持数千个方块
- **实时交互**：
  - 轨道控制：旋转、缩放、平移
  - 游戏视角：WASD + 鼠标第一人称视角
  - 方块选择：单选/框选/类型选择
  - 方块操作：复制/粘贴/删除/替换

#### 多变体生成
- 并行生成 3 个设计变体
- 实时预览对比
- 一键切换和应用
- 独立的历史记录

#### 导出系统
- **指令导出**：`/fill` 单行指令
- **mcfunction**：函数文件
- **NBT 结构**：原生 Minecraft 格式
- **WorldEdit**：`.schem` 格式
- **Litematica**：`.litematic` 投影格式
- **Axiom**：`.axbp` 蓝图格式
- **数据包**：完整数据包结构

#### 投影查看器
- **三视图**：俯视/正视/侧视并排显示
- **层切片**：任意高度层查看
- **网格线**：坐标轴标注
- **尺寸显示**：实时尺寸信息

#### 图片参考
- 上传参考图片（最多 3 张）
- Vision API 图生建筑
- 全屏图片查看器

#### 代码编辑器
- 实时代码查看和编辑
- 语法高亮（JavaScript）
- 代码历史记录
- AI 辅助修改

## 📖 使用教程

### 1. 配置 API

首次使用需要配置 API 密钥：

1. 点击右上角 **⚙️ 设置**
2. 输入 **API Key**
3. 选择 **模型**（推荐 `gpt-4` 或 `claude-3-5-sonnet-20241022`）
4. 配置 **Base URL**（可选，默认 OpenAI）
5. 点击 **保存设置**

### 2. 快速生成建筑

#### 方式一：快速模式（推荐新手）

1. 在底部输入框输入建筑描述：
   ```
   一座中世纪风格的石砖塔楼，高 15 格，带旗帜
   ```

2. 按 **Enter** 或点击 **发送** 按钮

3. 等待生成完成（10-30 秒）

4. 在 3D 视图中查看结果

5. 点击 **📋 复制指令** 导出到 Minecraft

#### 方式二：智能模式（最佳质量）

1. 输入详细描述：
   ```
   建造一座中世纪城堡的主塔楼
   - 材料：石砖、橡木、玻璃
   - 高度：20 格
   - 底部 7x7，顶部 5x5 逐层收缩
   - 四个角塔，带箭垛和旗帜
   - 内部有楼梯和房间
   ```

2. 选择 **智能模式**（默认）

3. 等待三阶段生成：
   - 📋 规划设计（10 秒）
   - 🏗️ 建造结构（20 秒）
   - ✨ 质量优化（10 秒）

4. 查看最终结果

#### 方式三：蓝图模式（交互式）

1. 输入基础描述：
   ```
   建造一座大型宫殿
   ```

2. 选择 **蓝图模式**

3. 回答 AI 问题：
   - 建筑风格？（中世纪/东方/现代）
   - 主要材料？
   - 特殊需求？

4. 查看蓝图预览（2D 平面图 + 3D 线框）

5. 点击 **批准建造** 开始生成

6. 等待完成（1-3 分钟）

#### 方式四：极致模式（最高质量）

> ⚠️ 需要支持 Vision API 的模型（如 Claude 3.5 Sonnet）

1. 输入复杂建筑描述：
   ```
   建造一座宏伟的中世纪大教堂
   - 哥特式风格
   - 高耸的尖顶和彩色玻璃窗
   - 对称的双塔设计
   - 内部有中殿和侧廊
   ```

2. 选择 **极致模式**

3. 自动迭代流程：
   - 🏗️ 第 1 轮：生成初始建筑
   - 📸 捕获多角度截图（正面/俯视/透视）
   - 🤖 AI 视觉分析（结构/风格/细节评分）
   - 📝 生成改进建议
   - 🔄 第 2 轮：根据反馈改进
   - 📸 再次分析...
   - ✅ 达到目标质量（8.5/10）或 3 轮后停止

4. 查看迭代报告：
   - 最终评分
   - 各轮评分变化
   - 总成本和耗时

### 3. 精确修改现有建筑

#### 步骤 1：选择区域

1. 生成或导入一个建筑

2. 选择 **精确修改模式**

3. 自动进入区域选择：
   - 出现绿色边界框
   - 拖动控制点调整大小
   - 拖动边界框移动位置

4. 按 **Enter** 确认选区

#### 步骤 2：描述修改

1. 输入修改需求：
   ```
   把这扇木门改成双开铁门，两侧加石砖柱子
   ```

2. AI 分析：
   - 识别选中区域类型
   - 分析周边风格
   - 保持材料一致性

3. 生成修改（30 秒 - 2 分钟）

4. 查看结果

### 4. 使用图片参考

1. 点击输入框上方的 **📷 图片** 按钮

2. 选择参考图片（最多 3 张）

3. 输入描述：
   ```
   参考图片中的建筑风格，建造一座类似的塔楼
   ```

4. 发送生成

5. AI 分析图片并生成

### 5. 3D 视图操作

#### 轨道控制模式（默认）

- **旋转**：鼠标左键拖动
- **缩放**：鼠标滚轮
- **平移**：鼠标右键拖动
- **居中**：双击建筑

#### 游戏视角模式

1. 点击右上角 **🎮 游戏视角**

2. 控制方式：
   - **WASD**：前后左右移动
   - **空格**：上升
   - **Shift**：下降
   - **鼠标**：转动视角
   - **ESC**：退出游戏视角

#### 方块选择

- **单选**：点击方块
- **框选**：按住 Shift 拖动
- **类型选择**：双击选中同类型方块
- **取消选择**：点击空白处

#### 方块操作

选中方块后，右侧面板显示：

- **材料信息**：类型、坐标
- **复制**：Ctrl+C
- **粘贴**：Ctrl+V
- **删除**：Delete
- **替换**：选择新材料
- **批量操作**：多选后统一操作

### 6. 投影查看器

1. 点击右上角 **📐 投影** 按钮

2. 查看三视图：
   - **俯视图**（Top）：从上往下
   - **正视图**（Front）：从正面
   - **侧视图**（Side）：从侧面

3. 层切片功能：
   - 拖动滑块选择高度（Y 层）
   - 查看特定层的方块分布
   - 适合检查内部结构

4. 导出视图：
   - 右键图片 → 另存为

### 7. 多变体生成

1. 输入描述后，自动生成 3 个变体

2. 顶部标签切换：
   - **变体 1** / **变体 2** / **变体 3**
   - 各自独立的 3D 视图

3. 选择最佳方案：
   - 比较不同设计
   - 切换查看细节

4. 应用变体：
   - 点击 **应用到主场景**

### 8. 导出到 Minecraft

#### 方法 1：指令导出（最简单）

1. 点击 **📋 复制指令**

2. 在 Minecraft 中：
   ```
   /fill x1 y1 z1 x2 y2 z2 stone
   /fill x1 y1 z1 x2 y2 z2 oak_planks
   ...
   ```

3. 逐行粘贴执行

#### 方法 2：函数文件

1. 点击 **💾 导出** → **mcfunction**

2. 保存 `build.mcfunction`

3. 放入数据包：
   ```
   saves/YourWorld/datapacks/buildings/data/buildings/functions/build.mcfunction
   ```

4. 在游戏中：
   ```
   /reload
   /function buildings:build
   ```

#### 方法 3：NBT 结构

1. 点击 **💾 导出** → **NBT 结构**

2. 保存 `structure.nbt`

3. 放入结构文件夹：
   ```
   saves/YourWorld/generated/minecraft/structures/structure.nbt
   ```

4. 在游戏中：
   ```
   /place structure minecraft:structure ~ ~ ~
   ```

#### 方法 4：WorldEdit（需要插件）

1. 点击 **💾 导出** → **WorldEdit**

2. 保存 `building.schem`

3. 放入 WorldEdit 文件夹：
   ```
   plugins/WorldEdit/schematics/building.schem
   ```

4. 在游戏中：
   ```
   //schem load building
   //paste
   ```

#### 方法 5：Litematica（需要 Mod）

1. 点击 **💾 导出** → **Litematica**

2. 保存 `building.litematic`

3. 放入 Litematica 文件夹：
   ```
   .minecraft/schematics/building.litematic
   ```

4. 在游戏中按 `M` 打开菜单加载

## 🎯 高级技巧

### 提示词优化

#### ✅ 好的提示词

```
建造一座中世纪风格的石砖城堡塔楼
- 底部 9x9，顶部 5x5，高 18 格
- 材料：石砖为主，橡木装饰，玻璃窗户
- 四个角有小塔楼，带箭垛
- 正面有橡木大门，门上方有窗户
- 顶部有红色旗帜
- 内部有螺旋楼梯连接各层
```

#### ❌ 不好的提示词

```
建一座城堡
```

**原因**：太模糊，缺少细节

#### 提示词要素

1. **建筑类型**：房屋/塔楼/桥梁/城墙...
2. **风格**：中世纪/现代/东方/幻想...
3. **材料**：石砖/橡木/玻璃/混凝土...
4. **尺寸**：长×宽×高
5. **特征**：门窗/装饰/颜色/对称性...
6. **功能**：内部结构/房间/楼梯...

### 材料选择建议

#### 常用材料组合

**中世纪风格**：
- 石砖 + 橡木 + 玻璃
- 圆石 + 云杉木 + 灰色混凝土

**现代风格**：
- 白色混凝土 + 玻璃 + 石英
- 灰色混凝土 + 黑色混凝土 + 玻璃板

**东方风格**：
- 深色橡木 + 红色混凝土 + 金块
- 云杉木 + 白色混凝土 + 红色陶瓦

**幻想风格**：
- 紫珀块 + 海晶灯 + 紫色玻璃
- 蓝冰 + 海晶石 + 青色玻璃

### 性能优化

#### 大型建筑处理

1. **分块生成**：
   - 大型建筑分多次生成
   - 每次 < 2000 方块

2. **使用蓝图模式**：
   - 先预览结构
   - 避免多次重生成

3. **降低渲染负载**：
   - 关闭不必要的视觉效果
   - 使用投影查看器检查

#### API 成本控制

1. **快速模式优先**：
   - 小型建筑用快速模式
   - Token 消耗 < 5000

2. **智能模式适中**：
   - 中型建筑
   - Token 消耗 5000-15000

3. **极致模式谨慎使用**：
   - 仅用于重要建筑
   - Vision API 成本 $0.045-0.20/次

## 🔧 故障排除

### 常见问题

#### 1. 生成失败

**症状**：显示 "生成失败" 错误

**可能原因**：
- API Key 无效
- 网络连接问题
- 模型不支持

**解决方案**：
1. 检查 API Key 是否正确
2. 测试网络连接
3. 尝试更换模型
4. 查看浏览器控制台错误日志

#### 2. 渲染卡顿

**症状**：3D 视图很慢

**可能原因**：
- 方块数量过多（> 5000）
- 硬件性能不足

**解决方案**：
1. 减少生成的方块数量
2. 关闭游戏视角模式
3. 降低浏览器缩放比例
4. 使用投影查看器代替 3D 视图

#### 3. 导出失败

**症状**：导出的文件无法使用

**可能原因**：
- 文件格式不兼容
- Minecraft 版本不匹配

**解决方案**：
1. 检查 Minecraft 版本
2. 尝试其他导出格式
3. 使用指令导出代替文件导出

#### 4. 精确修改不工作

**症状**：选区无法确认

**可能原因**：
- 未选中任何方块
- 选区太小或太大

**解决方案**：
1. 确保选区内有方块
2. 调整选区大小（5-500 方块）
3. 按 Enter 确认选区

### 调试模式

开启调试面板查看详细日志：

1. 按 **F12** 打开浏览器开发者工具
2. 点击右上角 **🔧 调试** 按钮
3. 查看：
   - API 请求日志
   - 方块生成日志
   - 错误堆栈信息
